# Machine Learning Projects

Small Python projects created while learning foundational machine-learning concepts, data preparation, classification, and prediction.

## Projects

### Perceptron Classification

**File:** `main_ perceptron.py`

Implements a perceptron classifier using the included zoo dataset.

- Initializes weights randomly
- Classifies examples using a weighted sum and bias
- Updates weights when a prediction is incorrect
- Reports training accuracy across epochs

### Dataset Correlation Experiment

**File:** `dataset_ correlation`

Uses the perceptron training process to estimate how strongly the selected dataset features relate to the target classification.

### Housing Price Prediction Model

**File:** `Housing Price Prediction Model`

An experimental housing-price prediction program built from scratch using the included `Housing.csv` dataset.

- Converts categorical housing features into numeric values
- Trains weights from the dataset
- Measures prediction error during training
- Accepts user-entered housing features and produces a predicted price

## Technologies

- Python
- pandas
- CSV data processing
- Perceptron learning
- Basic predictive modeling
